# Démo

La future interface Gradio sera une couche de présentation : dépôt WAV/MP3, lecture audio, spectrogramme, fenêtres analysées et top-3.

Elle appellera `music_genre.inference`, sans recopier le prétraitement, charger les données d’entraînement ni ajuster un scaler. Les contrôles et erreurs métier appartiendront au parcours d’inférence partagé.

Aucun serveur ou écran de démonstration n’est encore implémenté.
