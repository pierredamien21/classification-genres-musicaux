Objectif : lancer et suivre toi-même un CNN, puis revenir avec ses sorties. Recette fixée : graine 42 depuis zéro, 30 époques maximum, patience 5, AdamW à 0,001, sélection par macro-F1 de validation par morceau. Amélioration strictement positive (seuil 0) ; en cas d’égalité, garder la première époque. Le meilleur checkpoint est restauré. Budget d’apprentissage : deux heures.

La V1 utilisait patience 3 ; cette session teste une règle différente. Elle n’entraîne pas le ViT gelé par époques. Aucun gain n’est promis et aucun test V1 n’est consulté pendant cet entraînement complémentaire.

« Tout exécuter » est sans entraînement par défaut. Le lancement nécessite de changer LANCER = False en True dans une cellule dédiée. Ensuite, remettre la valeur à False. Le processus écrit ses sorties sur disque et continue si tu fermes ce notebook ; arrêter ou mettre le PC en veille interrompt le calcul.

2. Lancer volontairement¶

Une seule session complète est autorisée par le lanceur. Il vérifie les processus existants et les entraîneurs se protègent par verrou. Pour reprendre après arrêt, utiliser REPRENDRE = True avec LANCER = True ; la configuration, les données, le code et l’environnement doivent rester identiques.

Une époque incomplète n’est pas conservée. La reprise repart du dernier checkpoint complet avec optimiseur, état aléatoire, historique et compteur de patience.
