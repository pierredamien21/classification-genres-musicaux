# Rapports

`figures/` et `tables/` accueilleront les synthèses des expériences. Les sorties générées ne sont pas ajoutées automatiquement à Git ; les résultats retenus seront publiés explicitement avec leurs références d’exécution.

Futurs livrables : comparaison des systèmes, rapport d’erreurs, rapport de coût, fiche du dataset et fiche du modèle. Toujours distinguer résultats observés, hypothèses et travaux reportés.
